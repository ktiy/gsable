# Types

Sable supports the following types:

- [Number](#number)
- [Byte](#byte)
- [Character](#character)
- [Array](#array)
- [Function](#function)
- [Modifier](#modifier)

## Number
Numbers are 64-bit floats.
```
1 3.14
```

## Byte
Bytes are 8-bit unsigned integers.

Byte literals use a '#' followed by hexadecimal.
```
#0 #1 #2 #dd #ee #ff
```

## Character
Characters are unicode codepoints represented by 32-bit integers.

Character literals use a `'` followed by the character.
```
'a 'b 'c
```
